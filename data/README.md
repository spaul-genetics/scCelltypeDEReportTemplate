# Synthetic template data

All CSV files in this directory are generated by `scripts/generate_mock_data.R`.

- `mock_cells.csv.gz`: one synthetic row per cell with `cell_id`, `UMAP_1`, `UMAP_2`, `cluster`, `sample`, and `batch`.
- `cluster_hotspots.csv`: cluster-centroid positions normalized to the displayed UMAP image, used by the interactive circle overlay.
- `marker_summary.csv`: invented mean-expression, within-gene scaled-expression, and percent-expressing values for generic genes and clusters.
- `sample_composition.csv`: synthetic cell counts and within-cluster proportions.
- `de_results.csv.gz`: invented per-gene statistics for standard, prevalence-aware, and direct-mutant volcano examples.

These files illustrate interface contracts only. They are not suitable for biological interpretation or statistical benchmarking.
