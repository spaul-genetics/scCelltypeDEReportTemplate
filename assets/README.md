# Presentation assets

`RTB_Wheel.png` is the RTB_wheel logo used in the report header. It is a fixed presentation asset copied from the established NIAID-1263 report and is not generated from synthetic or analytical data. Quarto embeds the image into the self-contained HTML during rendering.

When rebranding the template, replace this PNG with the new approved logo and update the image alternative text in `report_template.qmd`. Preserve a transparent background and an approximately square aspect ratio so the existing header sizing remains suitable.
